# Pagamentos — módulo legado desabilitado

O **MarketAI Community é 100% gratuito** e não possui checkout, assinatura, trial pago ou plano Premium.

Este repositório ainda contém parte da antiga camada Multi-Gateway para compatibilidade histórica e referência técnica, porém a edição Community:

- não exibe meios de pagamento;
- não oferece planos pagos;
- não exige licença de uso;
- retorna a cobrança como desabilitada nas rotas públicas da edição Community.

As integrações antigas com Mercado Pago, Pix, Stripe e PayPal **não são necessárias para executar o MarketAI Community**.

Se você estiver estudando o código legado, nunca publique credenciais reais no repositório.
