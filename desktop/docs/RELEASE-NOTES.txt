MARKETAI 1.5.0 — LOCAL MODE, WITHOUT HOSTING

- Windows starts an embedded service and persistent local profile automatically.
- No Railway subscription, hosted server or Cloud login is required in local mode.
- Catalog, history, monitors, alerts, snapshots and batches use local SQLite.
- Sentinel and batch processing run while MarketAI is open. Interrupted batches
  resume when the app reopens. Recurring monitoring pauses when it is closed.
- Optional integration keys can be saved in Settings, protected with Windows DPAPI.
- Live market prices still require internet and available external providers;
  their credentials, terms, quotas or charges remain independent of MarketAI.
- Cloud catalog JSON backups can be reviewed and imported into the local profile.
  This does not retrieve data from an offline Railway instance or import market evidence.
- Previous remote sessions and existing preferences are preserved separately.
- Set MARKETAI_MODE=cloud and MARKETAI_CLOUD_URL to use your own hosted server.
- Back up the whole MarketAI data folder with the app closed to preserve all local
  records. DPAPI-protected credentials are tied to your Windows user/computer.
