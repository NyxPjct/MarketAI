MARKETAI 1.0.2 — COMMUNITY OPEN SOURCE

Mudanças principais:
- MarketAI agora é 100% gratuito para todas as contas
- removidos paywall, trial e cota mensal paga
- todos os módulos do Intelligence Core liberados
- login/criação de conta virou a tela principal do aplicativo
- cada usuário mantém seus próprios dados, histórico e monitoramentos
- checkout e ativação de licença desabilitados na edição Community
- licença open source Apache 2.0 adicionada ao repositório
- instaladores agora usam o número real da versão
- novo padrão: MarketAI-Setup-v1.0.2.exe
- documentação e ambiente de produção atualizados para Community/self-hosting

Também inclui:
- correção visual do Copilot
- Market Score 0–100
- Data Quality Score A–E
- Profit Engine
- Sentinel
- Radar
- Forecast
- Autopilot
- Copilot contextual
- alertas persistentes
- Desktop + Cloud + PostgreSQL + Sentinel Worker
- MarketAI nunca fabrica mediana, tendência, venda ou estoque quando faltam dados reais
