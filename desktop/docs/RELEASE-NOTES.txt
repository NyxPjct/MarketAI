MARKETAI 1.3.0 — SAVED SKU CATALOG, COMPARISONS AND BULK MONITORING

Saved account catalog:
- Create products manually or save selected valid CSV rows with a SKU.
- Keep variants, suppliers, manual stock, destinations, currencies and pricing inputs.
- SKUs are unique per account, case/Unicode normalized, and cannot be renamed.
- Import retries reuse identical products; conflicting existing data is preserved.
- Edit products with revision checks and inspect paginated change history.

Comparison and bulk actions:
- Search by product/SKU and filter data quality or changed pricing inputs.
- Sort across the catalog by margin, target price floor, SKU or last update.
- Show the latest trusted saved analysis, collection date and exchange-rate fallback.
- Flag results after pricing changes; supplier/stock edits preserve calculation status.
- Start new durable batches from selected catalog products without another CSV.
- Enable Sentinel for selected SKUs without duplicating monitors on retries.
- Catalog cost edits update the linked monitor without reactivating paused products.
- No orders, marketplace price changes or inventory synchronization are performed.
- Zero fees and zero target margins now remain zero during analysis.
- Catalog editor, controls, history and errors support five interface languages.

Validation and Windows:
- Cloud/Desktop tests exercise ownership, revisions, import conflicts, trusted
  results, changed inputs, pagination, monitor reuse and delete behavior.
- Browser regression exercises the catalog, comparisons, reanalysis and bulk monitoring
  across devices, alongside the existing batch/forecast/Copilot workflows.
- Windows release validation checks actual clean installation, native window startup
  and upgrades from v1.0.5, v1.1.0 and v1.2.0 while preserving preferences/user files.
- Tests use controlled data. Hosted login and live providers need separate validation.

Deployment and data:
- Deploy Cloud and Desktop v1.3.0 together. Back up the Cloud database first.
- Startup adds catalog_products, catalog_revisions and catalog_analyses without
  altering existing tables. Keep the Cloud API running for durable batches.
- Sentinel remains a separate worker for recurring collections.
- Deleting a product removes its catalog revisions/comparison links and pauses its
  monitor. Saved History analyses and prior snapshots/alerts remain separate.
- Clearing History removes linked comparison results, preserving catalog inputs.
- The local History/watchlist backup export does not include the saved catalog;
  use Cloud database backups for catalog inputs and revisions.

Community remains free, open source and without paid MarketAI quotas.
