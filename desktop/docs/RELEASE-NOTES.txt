MARKETAI 1.0.4 — MULTILINGUAL COMMUNITY RELEASE

Main changes:
- English is now the default interface language
- added full in-app language switching
- supported languages:
  - English
  - Português (Brasil)
  - Deutsch
  - Español
  - Français
- language selector available on the login screen and in Settings
- selected language is persisted on the device
- navigation, forms, account screens, Intelligence Core, modal messages and dynamic UI states follow the selected language
- date and currency formatting follow the selected locale
- authentication errors and account-created confirmation are localized
- common market quality/status messages are localized
- README fully rewritten in English
- README screenshots are generated in English
- screenshot automation validates all five supported languages before publishing images

Community foundation preserved:
- 100% free and open source
- no paid plans or monthly MarketAI quota
- account-isolated data
- monochrome black-and-white market theme
- Radar, Sentinel, Forecast, Profit Engine, Copilot and Autopilot
- MarketAI does not fabricate market prices, stock, sales or trends when real evidence is insufficient
