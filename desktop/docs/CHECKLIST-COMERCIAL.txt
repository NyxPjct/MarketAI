MARKETAI COMMUNITY — CHECKLIST DE RELEASE

[BASE DO PROJETO]
- MarketAI 100% gratuito para todas as contas;
- código-fonte distribuído sob Apache License 2.0;
- login / criação de conta como tela inicial;
- dados persistentes separados por conta;
- Intelligence Core liberado sem paywall;
- análises sem cota mensal paga;
- Sentinel, Radar, Forecast, Profit Engine, Autopilot e Copilot liberados;
- preços fictícios continuam proibidos;
- instalador usa o número real da versão;
- SHA-256 e provenance gerados no pipeline;
- suporte opcional a Code Signing;
- Cloud, PostgreSQL e Sentinel Worker suportados;
- self-hosting documentado.

[ANTES DE PUBLICAR UMA NOVA VERSÃO]
1. Atualizar a versão no Desktop e no instalador.
2. Atualizar .release/windows.json.
3. Rodar a suíte Cloud e Desktop.
4. Validar node --check frontend/app.js.
5. Testar login e criação de conta.
6. Confirmar que uma conta não acessa dados de outra.
7. Confirmar que não há paywall, checkout ou bloqueio por plano na experiência Community.
8. Testar uma análise com dados reais e outra sem amostra suficiente.
9. Testar Sentinel, Radar, Forecast e Copilot.
10. Testar o instalador em Windows 10/11 quando possível.
11. Validar o SHA-256 do instalador.
12. Confirmar que nenhuma credencial real entrou no repositório.
13. Se disponível, aplicar Code Signing.
14. Verificar o manifesto do auto-update.

[IMPORTANTE]
O MarketAI é gratuito, mas APIs, hospedagem e serviços externos podem ter custos,
cotas ou termos próprios. Isso não cria um plano pago dentro do MarketAI.
