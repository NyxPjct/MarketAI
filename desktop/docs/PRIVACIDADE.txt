MARKETAI COMMUNITY — NOTA DE PRIVACIDADE
Última atualização: 08/10/2026

1. CONTAS
O MarketAI pode tratar nome, e-mail, identificador aleatório da instalação e
informações técnicas necessárias para autenticação, segurança e funcionamento
da conta.

2. DADOS POR USUÁRIO
Análises, produtos monitorados, snapshots, alertas e demais dados persistentes
do Intelligence Core são associados ao usuário autenticado. A arquitetura deve
impedir que uma conta consulte os dados privados de outra.

3. ANÁLISES
Termos de busca, variante, país, custos informados e, quando utilizada, a imagem
do produto podem ser enviados ao MarketAI Cloud para executar a análise. O
servidor pode encaminhar os dados estritamente necessários às fontes externas
configuradas pelo operador da instância.

4. SERVIÇOS EXTERNOS
Marketplaces, agregadores, provedores de IA, câmbio e hospedagem possuem
políticas próprias. Uma instalação auto-hospedada pode escolher quais serviços
externos utilizar.

5. CREDENCIAIS
Tokens e chaves de integrações não devem ser incluídos no executável público nem
publicados no repositório. Na arquitetura hospedada, credenciais sensíveis ficam
no servidor. No modo local/self-host, são responsabilidade do operador.

6. DADOS LOCAIS
O Desktop pode manter preferências, histórico local, logs técnicos e a sessão da
conta. No Windows, a sessão pode ser protegida com DPAPI. O identificador da
instalação é um UUID aleatório; o MarketAI não depende de fingerprint invasivo
de hardware.

7. PAGAMENTOS
A edição Community não exige pagamento, assinatura ou licença comercial para
usar os recursos do MarketAI.

8. EXCLUSÃO E RETENÇÃO
Dados locais podem ser removidos do computador. Quem opera uma instância pública
do Cloud deve definir procedimentos de retenção, backup, acesso, correção e
exclusão compatíveis com a legislação aplicável.

9. OPEN SOURCE
O código do MarketAI é público, mas isso não torna públicos os dados privados,
tokens ou conteúdo das contas dos usuários.
